# ec-cube

This repository contains simple tools and plugins for EC-CUBE.

EC-CUBE 関連の簡易ツールとプラグインを置くリポジトリ

## Structure

- `plugins/`: EC-CUBE plugins
- `tools/`: Simple development utilities
-  - `price_update/` : Update the prices in the product master.
-  - `image_update/` : Bulk update product images.
