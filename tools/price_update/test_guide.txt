================================================================================
EC-CUBE 商品価格改定 機能テストガイド
================================================================================

このフォルダのファイルを使用して、安全に価格改定ツールの機能テストを行うための手順書です。
実データ・本番固有情報は含まず、架空のテストデータのみを使用しています。

--------------------------------------------------------------------------------
1. ファイル構成
--------------------------------------------------------------------------------
- product_newprice.csv         : 価格改定指示CSV (テスト用架空データ / 3商品・7規格)
- init_test_data.sql           : テーブル作成 & 改定前データ投入用SQL
- generate_price_update_sql.py : CSVから更新SQLを生成するPythonスクリプト
- update_prices.sql            : 改定実行用SQL (生成スクリプトの出力結果)
- price_update_guide.md        : 本ツールの全体マニュアル

--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
3. テスト実行手順
--------------------------------------------------------------------------------

■ ステップ1: テストテーブル作成 & 改定前初期データの投入
phpMyAdminのインポート、または以下のコマンドで「init_test_data.sql」を実行します。
(※ 何度再実行しても初期状態にリセットされます)

  mysql -h <ホスト> -u <ユーザー> -p <テストDB名> < init_test_data.sql


■ ステップ2: 価格改定SQLの生成 (必要な場合)
CSVを編集した場合はスクリプトでSQLを再生成します。

  python3 generate_price_update_sql.py product_newprice.csv -o update_prices.sql


■ ステップ3: 価格改定SQLの実行
生成された「update_prices.sql」を実行します。

  mysql -h <ホスト> -u <ユーザー> -p <テストDB名> < update_prices.sql


■ ステップ4: 結果の確認
以下の確認用クエリを実行し、価格・更新日時が正しく更新されたか確認します。

--------------------------------------------------------------------------------
4. 結果確認用クエリ & 期待される結果
--------------------------------------------------------------------------------

【SQLクエリ】
SELECT 
  pc.id AS `規格ID`,
  pc.product_id AS `商品ID`,
  p.name AS `商品名`,
  pc.product_code AS `コード`,
  pc.class_category_id1 AS `規格1`,
  pc.class_category_id2 AS `規格2`,
  pc.price01 AS `通常価格`,
  pc.price02 AS `販売価格`,
  pc.visible AS `表示`,
  pc.update_date AS `更新日時`
FROM dtb_product_class pc
LEFT JOIN dtb_product p ON pc.product_id = p.id
WHERE pc.product_id IN (101, 102, 103)
ORDER BY pc.product_id, pc.id;
